# AI資格学習（初期版）
Android向けPWA。20問の4択、採点、解説、復習、成績、JSONバックアップに対応。

## 起動
静的Webサーバーにこのフォルダを配置し、HTTPSのURLでアクセスします。Android Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

## 現在の制限
- 毎日のAI自動生成・毎朝6時の定期実行は**未実装**です。Gemini APIキーや無料ホスティングの設定が必要です。
- 初回診断の85%は表示上の参考値で、アプリ内の成績とは別管理です。
- 問題は初期収録20問のみ。今日すべて解いた後は翌日まで通常演習の対象がありません。
- 問題IDは配列位置で管理しているため、今後問題を追加する際はデータ移行が必要です。
- 個人情報やAPIキーをブラウザのJavaScriptに埋め込まないでください。
